# قاعدة البيانات الأساسية

`legacy_core_schema.sql` هو لقطة إعادة بناء للجداول التشغيلية التي سبقت اعتماد ملفات الترحيل.

يُستخدم فقط عند إنشاء مشروع Supabase فارغ بالكامل، بالترتيب التالي:

1. تشغيل `legacy_core_schema.sql`.
2. تشغيل ملفات `supabase/migrations/` بترتيب أسمائها.
3. نشر Edge Function الموجودة في `supabase/functions/admin-users/`.
4. تشغيل أحدث ملفات `supabase/verification/`.
5. إنشاء أول حساب إداري من قناة موثوقة، ثم التأكد من أن التسجيل العام معطل.

لا تشغّل ملف الأساس على قاعدة الإنتاج الحالية؛ سيتوقف عمدًا إذا وجد أي جدول تشغيلي موجود.
