# أمان CCE StableOS

## نموذج الثقة

الواجهة العامة غير موثوقة. أي قيمة سعر أو حالة أو سعة قادمة من المتصفح لا تُعتمد. Supabase Auth يثبت الهوية، وRLS/RPC داخل PostgreSQL تفرض الصلاحيات.

## الحسابات

- الحساب الجديد غير نشط وبدون دور افتراضيًا.
- Edge Function `admin-users` هي قناة إنشاء وتفعيل المستخدمين وتعيين الأدوار.
- يجب تعطيل التسجيل العام من لوحة Supabase Auth؛ إعداد قاعدة البيانات يمنع الوصول حتى لو أُنشئ حساب خارجيًا.
- لا توضع Service Role Key في GitHub Pages أو أي JavaScript عام.

## مصفوفة البيانات الحساسة

| البيانات | مكان التخزين | صلاحية القراءة |
|---|---|---|
| الخدمة والتاريخ وحالة الحجز | `booking_requests` | `bookings.view` |
| الهاتف التشغيلي | `booking_requests` | `bookings.view` |
| الهوية والطوارئ والصحة | `booking_private_details` | `bookings.sensitive.view` عبر RPC فقط |
| المبلغ وحالة الدفع | `income` | `income.view` أو سياسة الحجز المناسبة |
| دليل المدربين للنماذج | `id`, `name`, `active` فقط عبر `cce_instructor_directory` | صلاحية دخل أو جدول أو مدربين مناسبة |
| التاريخ الصحي | `horse_health_events` | حسب `event_scope` والصلاحية المقابلة |

لا تستخدم نماذج المالية والجدول قراءة `instructors.*` للحصول على قائمة الاختيار عندما لا يملك الحساب صلاحية إدارة المدربين. RPC الدليلية في v4.8.0 لا تعيد كلمة المرور المخزنة أو الهاتف.

## الحجوزات العامة

`cce_public_submit_booking` يفرض السعر والمدة وعدد الحصص ووحدات السعة، يتحقق من نسخة الشروط، يمنع التكرار السريع، ويقفل تاريخ الحجز أثناء فحص السعة. العملية كلها تنجح أو تفشل كوحدة واحدة.

## التدقيق والاحتفاظ

- قراءة بيانات سلامة الراكب تسجل `read_sensitive` دون نسخ المحتوى الحساس إلى سجل التدقيق.
- تاريخ انتهاء الاحتفاظ الافتراضي 180 يومًا، وتتوقف RPC عن إعادة الحقول الحساسة بعد انتهائه.
- الحذف الدوري التلقائي لم يُفعّل بعد؛ يجب عدم اعتبار `retention_expires_at` وحده عملية حذف.

## قائمة مراجعة دورية

1. مراجعة المستخدمين النشطين والأدوار والصلاحيات المخصصة.
2. التأكد من تعطيل التسجيل العام وعدم تسرب Service Role Key.
3. تشغيل اختبارات RLS لكل دور على مشروع تجريبي.
4. مراجعة سجلات `read_sensitive` والمحاولات غير الطبيعية.
5. تدوير الأسرار عند الاشتباه، وتوثيق الحادث والإجراء.
