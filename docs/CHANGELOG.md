# سجل تغييرات CCE StableOS

يتبع السجل ترتيبًا تنازليًا. تُكتب التغييرات المؤثرة في المستخدم أو قاعدة البيانات، ولا تُسجل التعديلات الشكلية الداخلية غير المهمة.

## 4.10.0 — Show Office Sprint 2

### Classes

- إضافة صفحة Classes أصلية داخل Show Office مع اختيار البطولة والبحث وفلتر النوع وJump-Off وتصميم بطاقات للجوال وجدول لسطح المكتب.
- إضافة CRUD للفئات يشمل رقمًا نصيًا وترتيبًا رقميًا والاسم والارتفاع ونوع المسابقة والأوقات وJump-Off والرسم والملاحظات.
- إظهار إجمالي الفئات الحقيقي في Dashboard ومنع حذف بطولة تحتوي فئات.

### Database, Security and Backup

- إضافة `show_office_classes` بقيود PostgreSQL وفهارس وتدقيق وصلاحيات RLS مستقلة، مع منح افتراضي لـManager وSuper Admin.
- إضافة استعادة ذرية مجمعة للمسابقات والفئات بمفاتيح بطولة محمولة، ومنع التكرار وفصل تقرير كل كيان، مع استمرار قبول نسخ v4.9.1 دون Classes.
- تصدير كل المسابقات والفئات مباشرة من Supabase بتصفح Keyset، وإضافة ورقتين مستقلتين في نسخة Excel.
- إضافة Preflight وVerification وRollback توافقي يحفظ جميع بيانات الفئات، واختبارات للقيود وRLS والتدقيق ومنع حذف الأب والتصدير الكامل والاستعادة والرجوع.
- حصر دليل المسابقات لمستخدمي Classes في المعرف والاسم والتاريخ عبر RPC، وتصحيح اتجاه LTR وأهداف اللمس وإظهار فشل تحديث البيانات بوضوح.

## 4.9.1 — Show Office Sprint 1.1

### Backup Restore

- إبقاء واجهة Show Office الأحدث من `main` مع نقل مصدر بياناتها من `localStorage` إلى خدمة Supabase واحدة، دون تكرار Controller أو CRUD.
- تصدير كل مسابقات Show Office مباشرة من Supabase بتصفح Keyset دون الاعتماد على حالة الواجهة أو حد القائمة، وإلغاء النسخة كاملة إذا فشل أي موفر مسجل.
- استعادة `modules.showOffice.competitions` من نسخ JSON الحالية، مع استمرار دعم النسخ القديمة التي لا تحتوي على `modules` أو Show Office.
- التحقق الصارم من بنية الملف والحقول والتواريخ والحالات والأطوال قبل أي كتابة للمسابقات.
- إضافة RPC ذرية تمنع التكرار وفق الاسم الموحّد والتاريخ، وتعيد أعداد المستورد والمكرر بدقة.
- تجاهل IDs والطوابع وهويات التدقيق الواردة من الملف؛ السجل الجديد يُختم بمستخدم الاستعادة، والمكرر يبقى دون تعديل.
- إضافة قيود PostgreSQL للأطوال المطابقة للواجهة، وفصل مكررات Show Office عن صفوف الجداول القديمة الفاشلة في تقرير الاستعادة.
- إضافة اختبارات JavaScript وPostgreSQL للتصدير الكامل، وفشل الموفر، والاستعادة الحالية والقديمة، والذرية، والصلاحيات، والتدقيق والتكرار.

## 4.8.3 — Instructor logout hotfix

### Authentication UI

- إعادة زر تسجيل خروج واحد إلى الترويسة العامة في بوابة المدرب على الجوال وسطح المكتب.
- الإبقاء على زر بوابة المدرب القديم مخفيًا لمنع عودة مشكلة تكرار أزرار تسجيل الخروج.
- لا يتضمن هذا الإصدار أي تعديل على قاعدة البيانات أو مبالغ التدريب والحسابات.

## 4.8.2 — Training schedule assignment and filters

### Training and Schedule

- تحويل كل موعد في باقة التدريب إلى سجل مستقل في `schedule` عند اختيار المدرب من صفحة الحجوزات.
- ربط الحصة بالحجز ورقم الموعد داخل الباقة، مع قيد فريد يمنع إنشاء الحصة مرتين عند إعادة الحفظ.
- إسناد الحصص إلى المدرب المختار عبر `instructor_id` لتظهر مباشرة في بوابة المدرب.
- إبقاء حالة الدفع مستقلة عن حالة الحصة؛ دفع الباقة لا يجعل الحصص `Done` تلقائيًا.
- إضافة فلاتر `All / Scheduled / Done / Pending / Cancelled` لجدول الإدارة وفلاتر الحالات لبوابة المدرب، مع عرض كل التواريخ افتراضيًا.

### Safety and UI

- إضافة حارس مالي داخل الترحيل وعملية الجدولة يمنع تغيير `amount_bd` أو `paid_bd` أو المتبقي.
- إصلاح ظهور زري Logout معًا على سطح المكتب بإعطاء حالة `hidden` أولوية صحيحة داخل نظام الترويسة.
- إضافة Preflight وVerification واختبار تكاملي لباقة من 8 حصص يثبت الإسناد، عدم التكرار، وظهور جميع الحصص للمدرب.

- إضافة كتالوج خدمة خادمي و`booking_requests` وربط فريد مع `income`.

- إعادة احتساب ملخصات Farrier وDental وDeworming وVaccination وMedication بعد الإضافة أو التعديل أو الحذف.

- استعادة سلسلة Supabase التاريخية وإضافة مخطط أساس قابل لإعادة البناء وملفات Preflight وVerification وRollback توافقي.

### Application

- ربط نماذج الركوب والتدريب والإيواء بالمعاملة الذرية الجديدة.
- فصل حالة الطلب عن حالة الدفع داخل شاشة الحجوزات، وإضافة انتقالات حالة محكومة.
- عرض طلب الإيواء بنوعه الصحيح، وربط رقم اتصال الطلب بتذكير الدفع دون وضعه في ملاحظات المالية.

- إضافة طلبات الحجز إلى ملف النسخة الاحتياطية المحلي.

### Quality

- إضافة GitHub Actions و18 اختبارًا تشمل الأصول المحلية وبناء سلسلة PostgreSQL كاملة من قاعدة فارغة.
- اختبار فعلي لمنع الإدخال المجهول، الحجز الذري، الحساب غير النشط، وفallback ملخص صحة الخيل بعد حذف أحدث حدث.

### Deployment
