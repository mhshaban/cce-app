# سجل تغييرات CCE StableOS

يتبع السجل ترتيبًا تنازليًا. تُكتب التغييرات المؤثرة في المستخدم أو قاعدة البيانات، ولا تُسجل التعديلات الشكلية الداخلية غير المهمة.

## 4.6.5 — Hotfix

### Security

- تنقية بيانات الحجز والتدريب والإيواء قبل عرضها في جدول الحجوزات والنوافذ وملخصات WhatsApp وصفحات النجاح.
- وضع حدود طول لمدخلات النماذج العامة لتقليل الإدخالات غير الطبيعية.

### Fixed

- منع ظهور `Add Plan` للمصروف المدفوع، وإضافة حارس يمنع إنشاء خطة له حتى عند استدعاء العملية مباشرة.
- منع تعديل خطة الأقساط من إعادة احتساب `Paid BD` أو تصفيره دون عملية دفع صريحة.
- منع خطة الأقساط من تجاوز الرصيد المتبقي، وتسوية الرصيد غير المخطط له بأمان عند `Mark Paid`.
- تحويل `Recent Sessions` إلى `Recent Financial Activity` لعرض آخر عمليات الدخل والمصروفات معًا.
- استخدام تاريخ البحرين لدفعات الأقساط وطلبات الإيواء الافتراضية.
- جعل تذكير الساعة وتذكير 24 ساعة متنافيين لمنع الإرسال المكرر.
- توحيد مفاتيح Cache وإصدار النسخ الاحتياطي وهوية PWA مع الإصدار 4.6.5.

## 4.6.4 — قيد المراجعة

### Fixed

- توحيد Safe Area للجوال على `env(safe-area-inset-top) + 8px` وحذف تعويض `+72px` من الشاشات الصغيرة.
- ربط إكمال أحداث Farrier وDental وDeworming وVaccination وMedication بملخص سجل الخيل عبر Trigger في قاعدة البيانات.
- إعادة تحميل جدول الخيل والأحداث وإعادة بناء التنبيهات مباشرة بعد إكمال مهمة صحية.
- إظهار الحالة التشغيلية والحالة الصحية بشكل مستقل في بطاقة الخيل.
- تحميل Horse Health حتى للحسابات التي تملك صلاحية الصحة دون الاعتماد الخاطئ على `horses.view` وحدها.
- السماح لحاملي `notifications.view` بفتح صفحة التنبيهات.
- إعادة بناء جرس التنبيهات بعد اكتمال التحميل، واستخدام خيل المالك في Owner Portal.
- إصلاح أسماء حقول تذكير الجلسات إلى `horse_name` و`customer_name` واحترام صلاحيات الجدول.
- استعادة خيار إشعار الحجز المحفوظ وتشغيل فحص الجدول اليومي دوريًا دون تكرار All Clear.
- تحسين عداد التنبيهات، طول ملخص الحجوزات، التمرير، Escape وخصائص ARIA.

### Documentation

- إنشاء الوثائق الرسمية للرؤية، الخارطة، المعمارية، قاعدة البيانات، الواجهة وسجل التغييرات.

### Database
