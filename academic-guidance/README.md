# رشاد — منصة الإرشاد الأكاديمي والتوجيه المهني

مشروع مستقل عن CCE StableOS، يعيش داخل هذا المستودع مؤقتًا تحت مجلد `academic-guidance/`، ويتّبع نفس القالب المعماري المستخدم في تطبيق CCE (واجهة HTML/CSS/JS بدون إطار عمل + Supabase مستقل + تصميم عربي RTL أولًا)، دون أي علاقة ببيانات أو مستخدمي CCE.

الحالة الحالية: **تخطيط (Planning) — لم يُنفَّذ أي كود بعد.**

## لماذا مجلد منفصل بدل مستودع GitHub جديد؟

جلسة العمل الحالية مصرّح لها بالوصول إلى مستودع `mhshaban/cce-app` فقط. لإنشاء مستودع GitHub مستقل فعليًا يلزم إما صلاحية إنشاء مستودعات جديدة أو إضافة مستودع فارغ موجود مسبقًا إلى الجلسة. إلى حين اتخاذ هذا القرار، يبقى المشروع هنا كوحدة كود مستقلة تمامًا (لا تستورد ولا تعتمد على أي ملف من جذر المستودع) بحيث يسهل نقلها لاحقًا إلى مستودعها الخاص بأمر `git filter-repo` أو `git subtree split` دون فقدان تاريخ الالتزامات.

## الخطوة التالية

بعد اعتماد هذه الخطة، الخطوة التالية هي إنشاء هيكل الكود الفعلي (`index.html`, `src/core`, `src/modules`, `supabase/baseline`, إلخ) على نفس نمط CCE StableOS، مشروع Supabase جديد مستقل بالكامل عن مشروع CCE، ثم بناء الإصدار الأول (MVP) حسب الترتيب في خارطة الطريق.
