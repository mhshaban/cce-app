# سجل تغييرات CCE StableOS

يتبع السجل ترتيبًا تنازليًا. تُكتب التغييرات المؤثرة في المستخدم أو قاعدة البيانات، ولا تُسجل التعديلات الشكلية الداخلية غير المهمة.

## 4.7.1 — Hotfix

### Fixed

- منع ظهور زري `Logout` معًا في ترويسة المدير عندما تُهيئ بوابة المالك في الخلفية.
- ربط زر الخروج بالبوابة المفتوحة فقط: Dashboard أو Owner Portal أو Trainer Portal.

### Quality

- إضافة اختبار انحدار يثبت وجود زر خروج واحد خاص بالبوابة النشطة.
- تحديث رقم الإصدار ومفاتيح Cache لضمان وصول الإصلاح إلى الأجهزة دون ملفات واجهة قديمة.

## 4.7.0 — Production release

### Security

- جعل ملفات حسابات Auth الجديدة غير نشطة وبدون دور حتى تفعيلها من الإدارة.
- إلغاء الإدخال المجهول المباشر إلى `income` ونقل الحجز العام إلى RPC محكومة.
- فصل الرقم الشخصي وتاريخ الميلاد والطوارئ والمعلومات الصحية في `booking_private_details`.
- إضافة `bookings.sensitive.view/manage` وتسجيل كل قراءة لبيانات السلامة في Audit Log.
- تضييق RLS لأحداث صحة الخيل حسب نطاق Medical وVaccination وCare.

### Database

- إضافة كتالوج خدمة خادمي و`booking_requests` وربط فريد مع `income`.
- التحقق الخادمي من السعر، الشروط، تاريخ ووقت الطلب، عدد حصص التدريب والسعة.
- استخدام Advisory Locks لمنع تجاوز السعة عند الطلبات المتزامنة وRate Limit قصير حسب الهاتف.
- إعادة احتساب ملخصات Farrier وDental وDeworming وVaccination وMedication بعد الإضافة أو التعديل أو الحذف.
- إضافة `created_at` و`updated_at` إلى الدخل والمصروفات والجدول مع Backfill.
- استعادة سلسلة Supabase التاريخية وإضافة مخطط أساس قابل لإعادة البناء وملفات Preflight وVerification وRollback توافقي.

### Application

- ربط نماذج الركوب والتدريب والإيواء بالمعاملة الذرية الجديدة.
- فصل حالة الطلب عن حالة الدفع داخل شاشة الحجوزات، وإضافة انتقالات حالة محكومة.
- عرض طلب الإيواء بنوعه الصحيح، وربط رقم اتصال الطلب بتذكير الدفع دون وضعه في ملاحظات المالية.
- استخدام تاريخ البحرين في الحد الأدنى لمواعيد التدريب وفي إكمال التطعيمات ونماذج الصحة.
- إضافة طلبات الحجز إلى ملف النسخة الاحتياطية المحلي.

### Quality

- إضافة GitHub Actions و18 اختبارًا تشمل الأصول المحلية وبناء سلسلة PostgreSQL كاملة من قاعدة فارغة.
- اختبار فعلي لمنع الإدخال المجهول، الحجز الذري، الحساب غير النشط، وفallback ملخص صحة الخيل بعد حذف أحدث حدث.

### Deployment

- طُبق ترحيل v4.7.0 على الإنتاج بعد النسخة الاحتياطية، واجتازت فحوص التحقق العشرة.
- نُشرت الواجهة على GitHub Pages، واجتازت فحوص CI واختبار الحجز العام دون كتابة اختبارية إضافية.

## 4.6.5 — Hotfix

### Security

- تنقية بيانات الحجز والتدريب والإيواء قبل عرضها في جدول الحجوزات والنوافذ وملخصات WhatsApp وصفحات النجاح.
- وضع حدود طول لمدخلات النماذج العامة لتقليل الإدخالات غير الطبيعية.

### Fixed

- منع ظهور `Add Plan` للمصروف المدفوع، وإضافة حارس يمنع إنشاء خطة له حتى عند استدعاء العملية مباشرة.
- منع تعديل خطة الأقساط من إعادة احتساب `Paid BD` أو تصفيره دون عملية دفع صريحة.
- منع خطة الأقساط من تجاوز الرصيد المتبقي، وتسوية الرصيد غير المخطط له بأمان عند `Mark Paid`.
- تحويل `Recent Sessions` إلى `Recent Financial Activity` لعرض آخر عمليات الدخل والمصروفات معًا.
- استخدام تاريخ البحرين لدفعات الأقساط وطلبات الإيواء الافتراضية.
- جعل تذكير الساعة وتذكير 24 ساعة متنافيين لمنع الإرسال المكرر.
- توحيد مفاتيح Cache وإصدار النسخ الاحتياطي وهوية PWA مع الإصدار 4.6.5.
