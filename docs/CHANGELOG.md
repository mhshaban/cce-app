# سجل تغييرات CCE StableOS

يتبع السجل ترتيبًا تنازليًا. تُكتب التغييرات المؤثرة في المستخدم أو قاعدة البيانات، ولا تُسجل التعديلات الشكلية الداخلية غير المهمة.

## 4.14.1 — Hotfix

### Performance

- إزالة التحديث التلقائي الدوري في لوحة Live Results بالكامل (كان يستطلع كل 8 ثوانٍ)، بعد تنبيه Supabase باستهلاك مرتفع لوحدة المعالجة. الآن تُجلب البيانات فقط عند فتح الصفحة أو الضغط على زر Refresh، دون أي طلبات خلفية دورية.
- إزالة مؤشر البث الحي النابض (النقطة الخضراء) من رأس اللوحة لأنه لم يعد يعكس سلوكًا حيًا فعليًا؛ يبقى وقت آخر تحديث ظاهرًا.

## 4.14.0 — تسجيل تحكيم بالحواجز (Fence-by-Fence)

### Judge Panel

- إضافة إعدادات اختيارية لكل فئة Table A: عدد الحواجز، قيمة نقاط الإسقاط، قيمة نقاط الرفض، وعدد الرفضات قبل الاستبعاد التلقائي — كلها قابلة للتعديل من نموذج الفئة، وتبقى الفئات بلا عدد حواجز على الإدخال اليدوي الحالي دون أي تغيير.
- إضافة لوحة حواجز تفاعلية في Judge Panel للفئات المفعّلة: كل حاجز زر يدوّر بين Clear → Knockdown → Refusal، ومجموع الأخطاء وعدد الرفضات يُحسبان تلقائيًا ويظهران فوق اللوحة مباشرة.
- استبعاد تلقائي عند بلوغ عتبة الرفض المحددة للفئة، مع بقاء خانة Eliminated قابلة للتصحيح يدويًا من الحكم قبل الحفظ.
- الوقت يبقى إدخالًا يدويًا كما هو الحال في وضع الإدخال العادي؛ لا ساعة توقيت داخل اللوحة.

### Database, Security and Backup

- إضافة `show_office_entry_fences` بقيود وفهارس وRLS مطابقة لصلاحيات نتائج Judge Panel/Live Results، مع تصحيح متزامن بواسطة `row_version` لكل حاجز على حدة.
- إضافة RPCs `cce_show_office_toggle_fence` و`cce_save_show_office_fence_score`؛ الثانية تحسب الأخطاء والرفضات من سجل الحواجز بدل إدخالها يدويًا، وتشارك نفس قفل الفئة المعتمدة (Finalized) والتحقق من حالة البطولة Running.
- توسيع `cce_show_office_judge_panel` بإعدادات الحواجز وحالة كل حاجز لكل جولة، وتحديث `cce_reset_show_office_score` لمسح سجل الحواجز أيضًا عند إعادة الضبط.
- توسيع استعادة الفئات الذرية (`cce_restore_show_office_competitions_classes`) لقبول حقول الحواجز الاختيارية مع بقاء التوافق الكامل مع نسخ أقدم لا تحتوي عليها.
- إضافة Preflight وVerification وRollback توافقي لا يحذف أي عمود أو جدول أو بيانات حواجز مُدخلة، واختبارات للتبديل والتأكيد والاستبعاد التلقائي وإعادة الضبط والاستعادة والرجوع.

## 4.13.0 — Show Office Sprint 5

- إضافة تحديث دوري تلقائي كل 8 ثوانٍ أثناء بقاء الصفحة مفتوحة ونشطة، مع مؤشر بث حي ووقت آخر تحديث، وتوقف تلقائي للتحديث عند مغادرة الصفحة أو إخفاء التبويب.
- إضافة وضع Big Screen يكبّر الترتيب ويخفي عناصر التحكم لعرضه على الشاشات الكبيرة، مع محاولة ملء الشاشة عند توفرها ونسخة مضغوطة للجوال.

### Database and Security

- إضافة صلاحية `show_office.results.view` ومنحها افتراضيًا لـSuper Admin وManager وJudge وReception وStaff، لإتاحة لوحة النتائج لموظفي الاستقبال دون منحهم Judge Panel.
- توسيع تحقق صلاحيات `cce_show_office_judging_context()` وو`cce_show_office_judge_panel(bigint)` ليقبلا `show_office.results.view` أيضًا، دون أي تغيير في شكل البيانات المرجعة أو في صلاحيات Judge Panel القائمة.
- إضافة Preflight وVerification وRollback توافقي يعيد التحقق إلى نطاق Sprint 4 فقط دون حذف أي جدول أو نتيجة أو سجل مراجعة.
